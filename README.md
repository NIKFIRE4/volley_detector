# 🏐 Volley Detector

**Volley Detector** — это система компьютерного зрения для анализа волейбольных матчей.  
Она включает в себя:

- детекцию игроков и мяча,  
- отслеживание их перемещений,  
- определение линий на площадке.


---

##  Возможности

-  **Детекция объектов**: определение положения игроков и мяча на каждом кадре видео.
-  **Отслеживание объектов**: использование алгоритма ByteTrack для отслеживания перемещений между кадрами.
-  **Обнаружение линий площадки**: определение границ волейбольной площадки для контекстуального анализа.
-  **Гибкая архитектура**: модульная структура кода позволяет адаптировать систему под другие виды спорта или задачи.

---

## 🧠 Используемые модели

- 🧠 **YOLOv8** — для детекции игроков и мяча на каждом кадре.
- 👣 **ByteTrack** — для отслеживания объектов между кадрами.
- 🧰 **OpenCV** — для базовой обработки изображений и визуализации результатов.
- 📍 **ResNet-50 (регрессия ключевых точек)** — кастомная модель, адаптированная для предсказания координат 10 ключевых точек волейбольной площадки:
  - Модель реализована в классе `CourtLineDetector`.
  - Архитектура: `ResNet-50`, последняя полносвязная (`fc`) заменена на слой с 20 выходами (по 2 координаты на каждую из 10 точек).
  - Предобработка изображений включает ресайз, нормализацию и преобразование к тензору.
  - Предсказанные координаты масштабируются обратно к размеру оригинального изображения.
  - Визуализация ключевых точек реализована методом `draw_keypoints`.
